# Cortex Lab: квиз-сайт

Одностраничный статический сайт (один файл `index.html`, без сборки).

## Как опубликовать через GitHub и Netlify

1. **GitHub.** Создайте новый репозиторий на github.com (например, `cortex-lab-quiz`).
   Загрузите в него все файлы из этой папки: кнопка *Add file → Upload files*.
   Или через терминал:
   ```
   git init
   git add .
   git commit -m "Первая версия сайта"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/cortex-lab-quiz.git
   git push -u origin main
   ```
2. **Netlify.** Зайдите на app.netlify.com → *Add new site → Import an existing project → GitHub*,
   разрешите доступ и выберите репозиторий.
3. **Настройки сборки.** Build command оставьте пустым, Publish directory: `.`
   (они уже заданы в `netlify.toml`). Нажмите *Deploy*.
4. **Готово.** Через минуту сайт откроется по адресу вида `название.netlify.app`.
   Любое изменение в GitHub будет автоматически публиковаться заново.

## Заявки (Formspree)

Адрес формы уже вставлен в `index.html` (поле `endpoint` в блоке `CFG`).
После публикации отправьте тестовую заявку и подтвердите почту в письме от Formspree.
Если в Formspree включено ограничение по домену, добавьте туда адрес вашего сайта на Netlify.

## Что можно менять

В начале скрипта в `index.html` находится блок `CFG`: название, заголовок, вопросы,
результат, почта и адрес формы. Телефон, Telegram и MAX меняются в блоке `<footer>` и в шапке.

## Важно

Текст политики конфиденциальности типовой. Перед запуском рекламы покажите его юристу
и при необходимости укажите полное наименование владельца сайта.
